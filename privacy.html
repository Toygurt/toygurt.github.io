Privacy Policy

Last updated: October 28, 2026

LB Games makes the mobile game LittleBall Run. We also use a small internal tool called LBA to read the statistics of our own social media accounts (YouTube and Instagram), such as views, likes and comments on our own videos.

LBA only reads data from accounts owned by LB Games. It does not access any other user's data. The data is stored only on our own computer, is used only to improve our own content, and is never sold or shared with anyone.

LBA's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

You can revoke LBA's access at any time from your Google Account permissions page.

YouTube API Services

LBA uses YouTube API Services. It uploads videos made by LB Games (original animations for LittleBall Run) to LB Games' own YouTube channel, and reads that channel's own statistics and analytics, such as views and audience retention. LBA is used only by LB Games. It does not access other people's YouTube channels or data.

By using these features you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What is stored: the Google sign-in (OAuth) token and our own channel's statistics. They are stored only on LB Games' own computer, are used only to publish and improve our own videos, and are never sold or shared with third parties.

Revoking access and deleting data: access can be revoked at any time from the Google security settings page. After access is revoked LBA can no longer read or upload anything, and the stored token and statistics can be deleted on request to the contact address below.

TikTok: LBA Studio posts LB Games' own videos to LB Games' own TikTok account using TikTok's Content Posting API. To do this it reads only basic profile info (user.info.basic) to show which account is connected. The access token is stored only on LB Games' own computer, nothing is shared with third parties, and access can be revoked at any time in TikTok's settings.
